# YuHua Chinese — HSK 3 Learning Hub v14

Bản này đã xóa hoàn toàn chức năng AI chấm bài.

## Dịch câu
Sau khi học sinh nhập câu tiếng Trung và bấm **So sánh với đáp án**:
- ký tự/nội dung trùng với đáp án gợi ý → màu đen
- ký tự/nội dung không trùng → màu đỏ
- hiển thị cả câu học sinh và đáp án gợi ý để đối chiếu
- có phần trăm mức độ trùng khớp ký tự

Lưu ý: đây là công cụ so sánh đáp án, không phải đánh giá ngữ pháp.

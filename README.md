# YuHua Chinese — HSK Learning Hub v19

Trang chủ mới gồm 3 mục chính:

1. Thông tin giáo viên
2. Thông tin lớp học
3. Ôn tập bài học

Khi bấm **Ôn tập bài học**, website mới hiển thị:
- HSK 1
- HSK 2
- HSK 3
- HSK 4
- HSK 5
- HSK 6

HSK 3 giữ nguyên toàn bộ bài học và bài tập trước đó.

# YuHua Chinese — HSK 3 Learning Hub v16

Bản v16 cải thiện 10 điểm về trải nghiệm học:

1. Trang chủ mô tả rõ mục tiêu HSK 3.0.
2. Module chia thành 3 bước học.
3. Phần dịch dùng khái niệm trùng/khác đáp án gợi ý.
4. Các ký tự liên tiếp cùng trạng thái được gom thành cụm để tô màu dễ đọc hơn.
5. Flashcard có Nhớ rồi / Chưa nhớ và lọc từ chưa nhớ.
6. Từ vựng có 1 ví dụ ngắn lấy ưu tiên từ bài khóa/bài dịch hiện có.
7. Bài khóa có Hiện / Ẩn pinyin.
8. Âm thanh có 2 tốc độ: Chậm và Bình thường.
9. Mỗi bài có mini quiz 8 câu tổng hợp.
10. Tiến độ được lưu bằng localStorage, không cần đăng nhập.

Pinyin được tạo trong trình duyệt bằng pinyin-pro 3.18.2 qua jsDelivr CDN.

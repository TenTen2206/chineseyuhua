# YuHua Chinese — HSK Learning Hub v25

Bản v25 cập nhật HSK 2 theo giáo trình đính kèm.

- 15 bài đều có từ vựng theo từng bài.
- Bài 1–14 có 4 bài khóa.
- Bài 15 giữ 3 bài khóa vì PDF nguồn kết thúc giữa Bài 15; không tự tạo phần còn thiếu.
- Từ vựng HSK2 dùng cùng cấu trúc với HSK3: Hán tự + pinyin + nghĩa tiếng Việt.
- Flashcard, phát âm, hiện/ẩn pinyin, điền từ và mini quiz sử dụng dữ liệu HSK2.
- HSK3 giữ nguyên.
